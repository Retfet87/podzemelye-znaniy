# Проверка изменений команды перед этапом 7

## Что сравнивалось

Стабильная ветка main оставалась на 459cc1c. Работа команды находится в bot на da084c3 и включает пять коммитов за 7 ноября. У веток независимые корневые коммиты. Проверенная версия сохраняет пакет app, новую регистрацию по направлениям, текстовые команды, удаление материалов и распознавание двух предметов в ячейке XLS. Миграции 001–005 совпадают со стабильной версией.

Вчерашние незавершённые Docker-файлы сохранены отдельным патчем и архивом в рабочей папке проверки. Они использованы как исходный материал для совместимой конфигурации Docker.

## Исправленные проблемы

- Без .dockerignore команда COPY . . включала бы локальные секреты и копии БД в образ. Контекст и COPY теперь ограничены исходниками и публичным сертификатом. Возвращены пустые примеры настроек.
- Docker передавал переменные окружения, а приложение читало только файл .env. Добавлен явный режим Compose с отдельным подключением к сервису postgres. Обычный локальный режим сохраняет loopback. TLS-проверки сохранены.
- Обычный Compose-запуск мог создать второй Long Polling с тем же токеном. Бот переведён в явный профиль live. Изолированный тест использует пустой токен и отдельную базу.
- Конвейер pg_dump | gzip мог скрыть ошибку дампа и удалить прежние архивы при ротации. Новый скрипт проверяет обе команды по отдельности, публикует готовый архив атомарным переименованием и сохраняет предыдущие копии.
- HTTP 403 при ответе одному пользователю завершал опрос для всех. Теперь такой ответ обрабатывается как ошибка отдельного события, 401 остаётся критическим.
- Супер-администратор, зарегистрированный в группе, терял меню общих заданий других групп. Список разрешённых групп восстановлен.
- Удаление материала двумя SQL-командами могло при гонке удалить вложения, даже если ревизия материала успела измениться. Используется одно удаление с проверкой ревизии и каскадом внешнего ключа.
- Подсказки меню могли перехватывать текст активного черновика. Роутер сначала передаёт обычный текст владельцу черновика, команды с / сохраняют переключение.
- Длинный список преподавателей мог превысить ограничение MAX. Страницы ограничены по длине текста, каталог требует регистрации, выборка учитывает действующие версии групп.
- Длинные списки направлений и групп разбиты на страницы. Запись в группу доступна из личного диалога.
- Серая заливка Excel больше не считается подтверждением другого корпуса по умолчанию. Для такого прочтения нужен явный флаг --gray-other-building после проверки легенды.
- Замены конкретной прошедшей даты блокируются. Базовое расписание по-прежнему можно обновлять с понедельника текущей недели, но сообщения о прошедших датах исключены.
- Seed-скрипт публиковал неподтверждённые кабинеты, часы работы и вымышленные мероприятия. Теперь он создаёт только помеченный демонстрационный черновик в отдельной тестовой базе по явному флагу.

## Проверки

В исходной bot выполнены 70 тестов с реальным XLS, один падал на изменённом контракте ответа callback. Исправленная версия: 82 теста прошли на отдельной PostgreSQL, включая реальный XLS и новые регрессии прав, черновиков, очередей, пагинации, конфигурации контейнеров и резервного копирования.

Статический анализ Python и аудит установленных зависимостей выполнены в отдельном окружении. Версии runtime-зависимостей закреплены. Ruff (E4, E7, E9, F), проверка синтаксиса shell и git diff --check прошли. pip-audit не нашёл известных уязвимостей в установленных зависимостях. Срабатывания Bandit на SQL-фрагментах проверены вручную. Пользовательские значения передаются параметрами psycopg, динамические фрагменты состоят из констант приложения.

Docker отсутствует на локальном Mac. Сборка, PostgreSQL, сохранение двух видов вложений после пересоздания контейнеров и настоящее восстановление архива включены в изолированный сценарий scripts/check_docker.sh и GitHub Actions.

Рабочий процесс MAX и рабочая база при проверке не останавливались. Схема рабочей базы не изменялась. Демонстрационные сообщения студентам не отправлялись.
