# Как устроен бот

`main.py` вызывает `app/bootstrap.py`: настройки, TLS, проверка схемы, блокировка единственного poller, зависимости и фоновые уведомления. `app/polling.py` получает события MAX и передаёт их в Router; временные ошибки MAX повторяются с задержкой.

`app/handlers/router.py` один раз разбирает событие в Context. Для личного запроса он открывает транзакцию, блокирует форму пользователя, восстанавливает черновик, вызывает обработчик и сохраняет результат. Публикация и закрытие формы атомарны. Исключение одного пользователя получает безопасный ответ и не должно остановить остальных.

## Где искать поведение

- `handlers/registration.py` — учреждение, направление, закрепление группы.
- `handlers/schedule.py`, `services/schedule_parser.py`, `schedule_publisher.py` — просмотр, XLS, сравнение и подтверждение. SQL выбор версии — `repositories/schedule.py`. Разовая замена действует только на своей дате, за пределами периода прогнозов нет.
- `handlers/homework.py` — задания: навигация отдельно от действий с карточкой и группой; форма отдельно от публикации. Права — `repositories/homework.py`.
- `handlers/community.py` — диспетчер разделов, отдельные методы списков, события, материала и сохранения. Права — `repositories/community.py`.
- `services/date_picker.py` — общий календарь формы. Он меняет только JSON-состояние выбора, но ничего не публикует.
- `handlers/questions.py` — распознавание коротких запросов и отдельные ответы из данных текущего пользователя, без LLM.
- `notifications/` — подготовка очередей и отправка. Worker выбирает самый ранний готовый элемент, при равенстве сохраняет приоритет событие → расписание → задание. Ограничение частоты, попытки и статусы хранятся в PostgreSQL. Абсолютная exactly-once доставка не обещается.
- `max_api/` — транспорт MAX и клавиатуры; пользовательские данные и токены не журналируются.

## База и формы

`app/db/database.py` управляет соединением и общей транзакцией формы; репозитории внутри неё работают через savepoint. Не добавляйте произвольный commit в обработчик формы: он разрушит атомарность. Пул по умолчанию выключен; при возврате соединения DISCARD ALL синхронно освобождает сессионные блокировки. Polling lease держит отдельное соединение вне пула; его потеря останавливает процесс, чтобы не допустить два poller.

Форма — ограниченный JSON с одноразовым токеном и сроком жизни. Изменение Draft требует defaults для старых payload и теста перезапуска. Существующие callback, SQL-поля и ключи конфигурации не переименовываются ради стиля.

## Как добавить раздел

Создайте обработчик с `on_message`/`on_callback`, возвращающими True только для своего события, и подключите его в `build_router` (`handlers/__init__.py`). Дайте callback свой префикс. Доступ к данным проверяется репозиторием, а не наличием кнопки. Новое сохранение формы должно остаться внутри транзакции Router. Добавьте тест маршрутизации, прав и повторного callback на отдельной БД.

DEMO использует отдельные DSN, роль и маркер; transport ограничивает адресатов, worker запрещён. Публичный сайт читает только вымышленные статические JSON и не подключается к рабочей базе. Это самостоятельный дополнительный продукт.
