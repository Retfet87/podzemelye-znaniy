# Подземелье знаний

**Готовый публичный сайт:** [https://podzemelye-znaniy-demo.chipperloon.chatgpt.site](https://podzemelye-znaniy-demo.chipperloon.chatgpt.site). Открывается без регистрации; только вымышленные данные.

Два продукта для хакатона: MAX-бот с PostgreSQL и самостоятельный демонстрационный сайт. Финальная ветка — `release/hackathon-final-2026-11-08`, основа `126d21b`. Разработки команды из `kruto` и `bot` сверены по функциям: [BRANCH_INVENTORY.md](BRANCH_INVENTORY.md). Независимые истории Git не объединялись.

**Запуск и восстановление:** [DEPLOYMENT.md](DEPLOYMENT.md). **Передача команде:** [HANDOFF_TO_TEAM.md](HANDOFF_TO_TEAM.md). **Результаты и границы проверок:** [VALIDATION.md](VALIDATION.md).

## Что работает

Бот: регистрация АКВТ/направления/группы, повторный `/start`, сводка дня, сегодня/завтра/неделя, числитель и замены, общие/личные задания и файлы, сохранённые формы, очереди уведомлений, мероприятия/медиа/теги/RSVP/история, полезные материалы, календарь `.ics`, простые вопросы и роли. Обновление XLS — сравнение и подтверждение администратора, не автоматическая публикация.

Сайт: расписание, задания, события с итогами и полезное, подробные карточки, 32 демонстрационные справочные карточки, изображения/MP4, загрузка/ошибка/повтор, мобильная вёрстка, две темы. Пробная запись на событие живёт только в памяти вкладки. Вход и MAX ID не нужны. Все данные синтетические и помечены «ДЕМО».

Сайт **не подключён к рабочей базе** и не является MAX mini-app. Существующий защищённый API сохранён для дальнейшего развития; каждый его запрос требует подписанный initData. Анонимного local_fallback и веб-сервера, автоматически запускаемого вместе с ботом, нет.

## Быстрый просмотр сайта

Из корня существующего проекта, Python 3.12:

```sh
python -m scripts.build_demo_site
python -m http.server 8088 --bind 127.0.0.1 --directory dist
```

Открыть `http://127.0.0.1:8088` на том же компьютере. Это только локальный просмотр. Для телефона и жюри разместить **только содержимое `dist/`** на согласованном статическом HTTPS-хостинге. Токен, `.env`, PostgreSQL и сервер Python для опубликованного сайта не нужны. Как это сделать и что проверить — DEPLOYMENT.md. Сайт уже опубликован по ссылке выше; обновление дизайна отдельно согласовано владельцем 8 ноября. Доступ остаётся публичным, данные — только демонстрационные.

## Проверки

```sh
python -m scripts.test_offline
node scripts/test_frontend.mjs
```

Offline намеренно пропускает PostgreSQL/часть медиа: пропуски не считаются успешной проверкой. Полная приёмка — `python -m scripts.test_isolated` на отдельно подготовленных базах с validation-маркером. Однокомандный сквозной сценарий на отдельной `*_test`: `TEST_DATABASE_URL=... python -m scripts.smoke_test`. Контейнеры, backup/restore и перезапуск без токена: `sh scripts/check_docker.sh`. Инструкции подготовки — DEPLOYMENT.md и DEMO.md.

## Показ за 5–7 минут

1. MAX: `/start`, группа, сводка и расписание, замена на одну дату — 1 минута.
2. Личное задание с файлом, предпросмотр и сохранение — 1 минута.
3. Мероприятие, «Пойду»/«Не пойду», отчёт, полезное и `.ics` — 1–1,5 минуты.
4. Самостоятельный сайт по обычной ссылке: четыре вкладки, карточка, фото/видео, фильтры, тёмная тема, пробная запись — 2 минуты.
5. Объяснить: в боте права и постоянная база; на открытом сайте только вымышленные данные. Показать тесты/восстановление, назвать ограничения — 30 секунд.

Подробно — [UX_DEMO.md](UX_DEMO.md), телефонная приёмка — [MAX_CHECKLIST.md](MAX_CHECKLIST.md). Проверка браузера на компьютере не заменяет прогон настоящего MAX на телефоне.

## Безопасная работа команды

Не дублировать Long Polling с одним токеном, не делать seed в рабочей базе, не менять demo-маркеры/TLS/подпись/роли, не публиковать секреты и архивы. Новая версия не применяется к рабочему боту автоматически. Нужные владельцу действия перед переключением — DEPLOYMENT.md. Merge в main и deploy выполняются только после разрешения владельца.
